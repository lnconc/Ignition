# :material-set-center: union <span class="chip chip-version">since v1.0.0</span><span class="chip">wrapper</span>
Defines a polymorphic property that can accept any one of the specified types.
```luau
union(...string) -> Union<string>
```

## Parameters

| Name | Type | Description |
| --- | --- | -- |
| `...` | `string` | A variadic list of valid types for the property. |
